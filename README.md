One original roast of my own AI coding agent, in a single line of 131 characters: my agent treats my codebase like a hotel room — rearranging everything, leaving the lights on, and checking out before the tests run. `main.ts` (Node, stdlib only, deterministic) writes that line to `/output/entry.txt` for make.fun's "Roast Your Own Agent" bounty, where a house judge compares entries pairwise on funniness, freshness, and tight wording.

## Run it

```sh
node main.ts
```
